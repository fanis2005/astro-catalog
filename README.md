# Каталог объектов для съёмок (SV545 / SV605CC)

Статический сайт-планировщик астрофотосессий: каталог объектов, видимость для 55.8N, Луна,
план ночи с выгрузкой серии NINA, учёт снятого.

Адрес: https://fanis2005.github.io/astro-catalog/

## Функционал

**Каталог (40 объектов).** Тип, созвездие, размер, звёздная величина, рекомендуемый фильтр,
сложность, заметка, превью. Для каждого объекта предрассчитана видимость для 55.8° N:
по 15-му числу каждого месяца — максимальная высота в астрономическую ночь и число часов
выше 30°.

**«Сейчас».** Объекты выше 25°, сортировка по текущей высоте; высота и азимут пересчитываются
каждую минуту. В карточке — метка «рядом Луна» (Луна выше горизонта, ярче 40 %, ближе 45°).

**«Календарь».** Таблица по выбранному месяцу: максимальная высота, часы выше 30°, фильтр,
сколько кадров уже снято.

**«План ночи».** Выбор объектов кнопкой «+ в план», расчёт тёмного окна (Солнце ниже −18°),
окон объектов (выше 30°), разбиение ночи на слоты и расписание. Две выгрузки:
- **JSON** — расширенная серия NINA 3.2 (`SequenceRootContainer`, `DeepSkyObjectContainer`,
  `SwitchFilter`, `Center`, `StartGuiding`, `TimeCondition`, `TakeExposure`, финиш с парковкой);
- **XML** — читаемое представление плана (архив/обмен, NINA 3 его не импортирует).

**Луна.** Фаза, возраст, высота, азимут; влияние на объекты — через метку «рядом Луна».

**Учёт снятого.** `tools/scan_shots.py` сканирует `Телескоп\Снимки с телескопа` и `N.I.N.A`,
считает кадры, часы, фильтры и дату последней ночи; данные попадают на карточки объектов.

**Статусы и заметки.** «в плане / хочу снять / снято» + заметка, экспорт/импорт JSON
(хранятся в localStorage браузера).

**Доступ.** Пароль на входе (клиентский). Для серверной авторизации — Worker в `../cloudflare`.

## Локальный запуск

Открыть `index.html` в браузере (file:// работает, данные подключены как JS).

## Обновление данных

```bash
python tools/build_catalog.py   # каталог и видимость
python tools/scan_shots.py      # что снято (папки Телескоп\Снимки с телескопа)
git add -A && git commit -m "обновление" && git push
```
